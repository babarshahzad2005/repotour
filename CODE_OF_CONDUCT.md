# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, assume good intent, welcome newcomers, and keep discussion focused on the work. Harassment, personal attacks, and discriminatory language are not tolerated in any project space, including issues, pull requests, and discussions.

## Reporting

Report unacceptable behavior privately to the maintainer at babarshahzad2005@gmail.com. Reports are handled confidentially, and the maintainer will respond as described in the Contributor Covenant's enforcement guidelines.
